Q: What is a javascript REPL? Can you name two ways to open one?

A: A JavaScript REPL is a tool that allows you to write and run JavaScript code one line at a time. REPL stands for Read-Eval-Print Loop – it reads your code, runs it (evaluates it), shows the result (prints), and then waits for the next line.

Two ways to open a JavaScript REPL are:

Browser Console – Right-click on a webpage, select Inspect, then go to the Console tab.

Node.js REPL – If you have Node.js installed, just type node in your terminal or command prompt and press Enter.
